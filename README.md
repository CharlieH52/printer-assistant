# Printer Assistant
## # Introduction
List all the printer devices in a system for the administration of them.

With this tool you would do:
- Check all the printer drivers installed.
- Uninstall any printer.
- Reset the queue service.
- Clean the queue print.
- Uninstall all printers except your choice.
- Uninstall all printers.

> [!CAUTION]
>
> Be careful with the bulk uninstall options. If you don't know what you are doing, please don't use them.

## # Requirements
* regEx
